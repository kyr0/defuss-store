# Changelog

## Unreleased

- **Breaking:** removed the `defuss-store/compat` legacy facade and its test suite; migrate to the core, `defuss-store/storage` and `defuss-store/persist` entry points.
- **Breaking:** removed the legacy equality aliases `deepEquals` (deprecated; use `jsonEquals`) and `shallowEquals` (identity equality; use the default or `Object.is`).
- Removed `NOTICE`, `SHA256SUMS` and the checked-in `artifacts/`; fixture provenance remains in `tests/fixtures/vendor/provenance.json`, and all release artifacts are regenerated by `npm run check`.
- **Types:** `get(key)` no longer types keys containing `.`, `[` or `]`, the empty key or unsafe segment names as `T[K]`. They are read as paths at runtime, so they now resolve to the `unknown` path overload.
- Fixed the release gate: `RELEASE.md` was required by `verify` and the `files` list but never existed. Lint now fails on oxlint warnings (`--deny-warnings`).
- `make verify` (lint, types, unit coverage, then build, browser, packed-consumer and package checks) replaces the separate `ci.yml` as the CI entry point; Playwright reports are written to `output/`.
- Build, verification and dev-server scripts are now TypeScript, executed with Node's native type stripping.
- Faster and smaller with no behavior change: paths are parsed in one char-code scan, path writes define keys through object literals instead of `Object.defineProperty`, commits reuse one listener snapshot until subscriptions change and skip queueing when nobody listens, and JSON validation tracks cycles on a stack instead of a `Set`. Measured against the previous build: path reads 1.2×, path writes 1.3–1.8×, listener-free commits 5×, selector fan-out 1.4× and large JSON persistence 1.3× faster; bundles are 4–10% smaller minified and 1–4% smaller gzipped.

## 0.1.0

- First standalone release candidate, extracted from the defuss store and isomorphic Web Storage contracts.
- Synchronous stores with immutable path updates, selectors, read-only computed values, stable queued notifications and deterministic teardown.
- Lazy native local/session storage, explicitly scoped memory adapters and strict JSON serialization.
- Validated versioned persistence, migration, manual hydration, error recovery and optional native cross-document synchronization.
- Optional bidirectional State API binding tested with actual defuss-shadcn tabs, pagination and sidebar.
- Scoped legacy raw-JSON facade and the 24 original store tests.
- ESM entries, declarations, source maps, standalone browser bundles, measured sizes, unit/browser/type/packed-consumer gates and release workflow.
- Correct path deletion, explicit null resets, empty keys, self-unsubscribe, nested notification values, persistence after listener errors and server memory isolation.
